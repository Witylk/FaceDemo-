
            人脸识别系统 (Face Recognition System) V2.0

【项目简介】
本项目是一个基于 Python 和 OpenCV 开发的高性能人脸识别系统。
它能够通过一张参考照片实现对图片库、文件夹以及视频流的快速检索与识别。

【核心功能】
1. 批量图片处理：自动扫描指定文件夹，识别出目标人物并分类保存。
2. 视频自动切片：在视频中发现目标人脸时，自动保存人脸截图作为数据集。
3. 实时监控识别：支持摄像头实时抓拍与身份比对。
4. 自动化训练：只需将目标照片放入 dataset 文件夹，程序即可自动学习特征。

【测试成果展示】
- 目标人物：奥巴马 (Barack Obama)
- 测试素材：包含5张混合图片的测试集 
- 识别准确率：成功从 5 张测试图中精准筛选出 3 张目标人脸，并将结果返回至dataset加强数据集的人脸特征，循环学习。
- 视频识别：实时跟踪视频中的人脸，并自动生成了 .jpg 格式的特征截图。（待各位自行测试）

【技术栈】
- 编程语言：Python 3.12
- 核心库：face_recognition (基于 dlib)
- 图像处理：OpenCV (cv2)
- 环境管理：Venv / GitHub 管理

【快速上手】
1. 将目标照片放入 /face_dataset/人物姓名/ 目录下。
2. 运行 main.py，选择选项 "3" 进行模型初始化。
3. 选择选项 "1" 进入识别模式，输入测试路径即可。

注意：一定记住要安装需要调用的requirements.txt里的软件包。
